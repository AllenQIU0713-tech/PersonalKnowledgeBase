# 资料与个人记忆共同检索：产品范围澄清

日期：2026-10-11。状态：产品澄清与验收补充，**不恢复独立记忆模块，不改变正式问答阻断状态**。

用户在审计任务的最新原话要求：提问检索既覆盖“收集模块”里的资料，也覆盖“我的记忆”中的内容；检索应理解问题意图，使用向量和余弦相似度，而非关键词包含。用户同时表示收集模块使用更频繁，并再次质疑“我的记忆”的作用。此要求明确的是**内容覆盖与检索方法**，没有要求重新创建记忆录入入口、页面、表或第二个向量库。

本产品解释：2026-09-30 已确认的单一资料库仍有效。旧个人记忆已按无损迁移规则映射为资料，保留旧标识、原状态、来源与历史；普通收集资料和合格迁移记忆在**同一向量索引**中参与提问。个人偏好、目标、经历等新的内容仍通过资料收集录入。用户所说“两部分内容”是来源意义上的两部分，不要求物理双库。“我的记忆”旧页面目前已移除；旧记忆可在资料详情中查阅来源和状态。若用户之后明确希望恢复专门管理页，再单独设计页面作用与成本。

## 1. 检索契约

提问先按现行资料资格、隐私、来源依赖和版本规则过滤，再对同一索引中所有合格资料片段生成本地问题向量、计算余弦相似度并召回候选。候选集合同时允许普通收集资料与来源类型为 `legacy_memory` 的迁移资料；不能按来源先排除任何一类，也不能只查旧记忆。个人自述若作为新文字资料录入，与普通资料使用同样的嵌入和排序流程。问题原词无需包含于标题或正文；独立精确查找仍可支持关键词，但不能取代自然语言提问。

余弦相似度仅衡量语义接近，用于召回和排序，**不是可回答性证明**。S1 实测显示高相似错人物、错属性与错编号会误放。S2 的本地证据复核应在召回之后判断同一对象及所问属性、事件、关系、批次和限定语是否由原文支持。精确编号硬边界可辅助，但不能重新建立词面主路径。当前本地复核候选均未通过完整质量门槛，因此自然语言问答继续 `calibration_required`；不能把“资料和记忆都能召回”写成已能可靠回答。

合格候选全部被复核拒绝时，明确返回资料不足；不得因关键词命中或高余弦值拼凑答案。回答及证据列表显示资料标题、资料标识、片段和来源类型。`legacy_memory` 仅作来源标识，不增加权重或真值优先级；来源互相冲突时展示冲突和各原文，不能静默采信记忆。多片段组合推理仍按 S2 的探索边界报告，不能用单片段通过冒充跨资料推理能力。

## 2. “我的记忆”的作用与当前状态

原“我的记忆”模块意在管理从资料抽取或手工写入的个人偏好、目标、经历和待确认事实。但它造成第二个录入与检索通道，用户已在 2026-09-30 要求移除。当前界面只有“收集”和“查找与提问”；旧记忆通过迁移保全，详情页能显示原状态、来源和历史。用户无需区分哪些内容该存为记忆：在收集页录入即可用于同一语义检索，前提是解析、资格、隐私与索引均就绪。

这也解释了为何“移除我的记忆模块”并不等于提问忘掉旧记忆。若现行实现中的旧记忆迁移、索引或资格过滤导致漏检，这是开发/测试缺陷，应按本契约修复，不通过恢复第二个库来掩盖问题。

## 3. 隐私与云端

`privacy=local`、待核对、停用、来源缺失或删除内容不得进入提问候选、上下文、云端预览、确认载荷、问答历史或最终回答；它们可在授权的本地浏览和精确查找中出现。旧记忆不能因迁移或来源标签获得更宽松资格。资料更新、隐私收紧、来源变化与删除须使向量索引、缓存和旧云端确认失效。

每次 DeepSeek 调用仍须先展示实际外发内容、目的及预期结果，等待单次确认。旧记忆来源标签不授权外发整份历史或画像。

## 4. 可测试的验收条件

1. 在同一固定语料中录入一条普通资料及一条合格旧迁移记忆，以不同词语表达同一类事实；同义改写问题分别应把目标片段召回。报告两条的资料/片段标识、来源、资格版本、余弦分数和排名，不仅展示最终答复。
2. 问题只与普通资料相关时能命中普通资料；只与旧记忆相关时能命中旧记忆。相同内容若有迁移映射，不因旧表与新资料重复参与召回或重复引用。新录入个人经历仍从资料收集进入同一索引。
3. 去掉题目与正文的共同关键词仍能完成语义召回；把错人物、错属性、错关系、错业务编号或计划当实际的高余弦片段放在前列时，证据复核必须拒绝。关键词排序或单个余弦阈值不能作为答复门禁。
4. 无合格答案时显示资料不足；只有不合格来源时不泄漏其正文。普通资料与旧记忆若互相冲突，分别展示来源与冲突，不能生成无依据的确定结论。
5. 旧记忆状态、隐私、来源依赖与历史可在迁移资料详情追溯；编辑、停用、隐私收紧、删除与旧备份恢复保持幂等和失效规则。正式回答及云端预览只包含本次通过资格与复核的真实片段。
6. 以上须在同一固定实现上通过独立测试、最终浏览器链路和审计。当前 S2/S2R1 模型失败及未执行的40候选性能测试不能用此设计澄清冲销；正式状态维持 `calibration_required`。

## 5. 交接范围

开发先对照现行 S1/S2 实现和本契约列出差距；若已有逻辑满足，不制造新模块变更。测试用混合来源语料验证资格→向量召回→证据复核→最终引用全链路。审计检查旧记忆迁移无损、来源标签、隐私泄漏和重复引用。Q6_K 来源审计及其新增资源批准仍是独立工作，不因本澄清自动放宽。
