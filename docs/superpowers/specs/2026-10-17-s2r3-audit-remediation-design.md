# S2R3 静态审计发现的产品修订

日期：2026-10-17。依据：`docs/audit/S2R3-candidate-9a5596e-static-review.md`。状态：产品批准隔离合成候选修订与测试设计，**不是静态 finding 关闭或正式问答启用批准**。适用于固定候选 `9a5596e40c8904b42bd6f019de8e88a73f83decc` 的下一版；不得在旧候选上改报告或重用旧冻结包。

## 1. 引文与 reviewer 身份（AUD-S2R3-01/02）

进入证据集合的每条逐字引文既要是原文连续子串，又要满足 `quote.strip()` 非空，并包含至少一个 Unicode 字母或数字字符。纯空格、制表、换行或仅标点不能作为证据。此处只排除无信息引文，不能把含字符的引用自动判为“回答了问题”；对象、属性、关系和限定语仍由复核质量门槛验证。对多条引文逐条检查，任一必要引文无效即拒该候选。测试保存空白、标点、有效日期/中文短语及引文裁剪边界原始输出。

reviewer 适配器向管线暴露只读 `config_signature` 和经启动验证的 manifest：实际模型文件 SHA-256、量化、提示模板/版本、生成参数、运行时版本与结果协议版本。生产管线从适配器读取并比对签名与预期固定 manifest，不能由调用方任意传一个非空字符串冒充。启动与每次结果核对均校验配置签名；漂移使问答整体不可用并使旧预览/确认失效。合成测试 double 可以有独立、明确标注为 `test-double` 的固定签名，用于验证接线，不得作为真实模型来源或质量证据。无需为签名新下载模型；Q6 的来源审批继续独立阻断。

## 2. 问答与浏览的状态分离（AUD-S2R3-03）

后端统一报告 `qa_state`，由 embedding/index 完整性、正式复核器注入、复核器来源/配置和质量校准状态共同决定。生产未注入 reviewer 时，无论数据库旧余弦阈值是否非空，`qa_state=blocked_by_missing_reviewer`，页面显示原因并禁用预览、模拟回答和云端准备按钮。相关 API 仍二次失败关闭，不能仅依赖前端。语义资料浏览继续按本地 embedding/浏览索引独立报告 ready/不可用；精确查找独立可用。

测试必须用隔离库构造“embedding ready + 非空测试阈值 + reviewer missing”，验证状态接口和真实页面均显示问答阻断、浏览可继续；注入测试 double 也只使隔离测试路径可测，不能使正式应用或用户页面误报生产 ready。

## 3. 多来源冲突（AUD-S2R3-04）

同一问题若有两条以上通过逐片段复核的证据，不能直接把它们交给生成模型自行挑选。下一版隔离候选增加**同一个本地 reviewer 的集合一致性检查**，不新增第三个模型或云端调用：输入仅为本次问题、已通过资格与逐片段复核的最多6条完整逐字引文及来源标识，不读取全库。输出固定 JSON：`verdict` 为 `consistent`、`conflict` 或 `uncertain`；`conflict` 必须给出至少一组冲突来源 ID 与各自可在原文核对的引文。输出无效、来源 ID 不在当前集合、引文伪造、服务失败或 `uncertain`，一律阻止确定性答复及云端准备。

`conflict` 时页面成组显示互相矛盾的原文和来源，禁止通过只取消一侧勾选来绕过冲突提示；确认票据不得创建。`consistent` 只表示该固定集合复核器在该输入上未识别出冲突，仍需独立正负例验证，不能自动证明事实正确。单条证据无跨来源冲突，但仍须通过逐片段复核。若用户再次提问、源版本或资格变化，重做集合检查，旧结果失效。

这是 S2 原“集合级复核需另行设计”在冲突场景的**显式候选设计**，不是静默增加一次模型请求。它可能增加本地延迟与内存；质量过门槛后要纳入完整40候选、至少20问的端到端 p50/p95、4–6GiB目标及8GiB保护停止线实测。集合复核质量若不达标，正式问答继续阻断，不能退回“只显示最高余弦来源”或交给 DeepSeek 自行判断。多文档互补推理仍为探索范围，本设计只解决同一问题下可用证据的冲突判定与显示。

冻结后的合成测试至少包括：不同来源一致陈述、不同人物相似陈述、同一对象互斥日期/地点或状态、计划与实际并存、明确否定与肯定、来源版本变化、用户试图只选一侧、伪造冲突 ID/引文、`uncertain` 和运行失败。全部冲突难负例不得形成确定性回答或云端确认；正例不能因仅有两份一致资料被一概拒绝。新盲测与稳定性要求沿 S2/S2R3 执行，不能在已暴露题上调提示择优。

## 4. 被拒候选的数据最小化（AUD-S2R3-05）

问答 preview API 可以返回拒绝原因代码与本次诊断计数，但不返回被拒片段正文或可被选择为证据的 ID；需要查看相关资料时由用户进入独立本地语义浏览，并显示其实际隐私/资格状态。被拒片段、受限资料、集合冲突状态均不得进入最终答案、云端 payload 或旧确认复用路径。测试针对本地 API 原始 JSON、页面对象、prepare/confirm 及 history/outbound 逐层验证，不以“当前UI没渲染”替代后端最小化。

## 5. 交接与通过条件

开发在独立任务基于本文件冻结新候选，列明旧候选与新候选差异；生产仍不注入未合格 reviewer。测试使用单一 registry/不可变 run bundle/preflight，对五项 finding 建立独立回归并保留审计原始证据；审计分别判断实现修复、合成测试、真实 reviewer 来源/质量和资源，不能合并为一个“通过”。既有 S2R2 浏览/两来源召回测试可独立推进，不因这次问答修订删除历史失败或重新解释测试专用阈值。

只有引文、签名、UI状态、冲突、API最小化均经独立测试和审计关闭，且真实本地 reviewer 完成来源、质量、40候选资源/延迟、最终浏览器与用户验收，才可讨论解除 `calibration_required`。当前没有要求用户作新的资源决定；Q6 仍为 `approval_blocked`，完整清单未审准前不请求下载批准。
