# 资料与个人记忆统一语义检索：产品变更草案

日期：2026-10-11。状态：**待用户确认，不是开发授权**。

审计任务转述用户最新要求：提问同时覆盖资料收集中的资料和个人记忆，按问题含义做向量语义检索；“我的记忆”页应有管理价值。它与 2026-09-30 用户确认的“去除我的记忆模块、统一从资料收集录入、只有一个资料向量索引”在页面去留上冲突。本草案采用最小范围的解释：恢复“我的记忆”管理视图，继续保留唯一资料收集入口、唯一底层资料存储和唯一向量索引。用户若要求重新独立录入或存储记忆，需要另行确认。未确认前，现行 S1/S2 规格和 `calibration_required` 状态不变。

## 1. 信息模型与页面

资料收集仍是文字、图片、PDF 和其他媒体的唯一新增入口。新增可选的“作为个人记忆展示”标记，用于个人偏好、目标、经历或自述；标记本身不自动改变隐私、资格或证据权重。旧 `memories` 表的内容继续按已批准的无损迁移映射到资料，不撤销迁移、不双写、不重新创建独立向量库。每条内容只有一个可检索资料标识；旧记忆标识和原状态、来源、历史仍可追溯。

“我的记忆”页是对这些个人资料的筛选和管理视图：集中查看、核对、修改、停用、删除以及打开原始来源。它显示旧迁移记忆和用户主动标记的个人资料，并解释每条内容当前是否有提问资格及原因。编辑动作修改同一条资料和索引版本，不制造第二份记录。删除沿用资料删除和墓碑规则。未标记为个人记忆的资料仍可被提问检索；“我的记忆”页不是问答唯一来源。

不从用户行为或云端回答自动创建个人画像。若将来引入自动整理的候选记忆，须作为另案设计、用户核对后保存；本变更不授权自动学习或自动写入。

## 2. 统一检索与证据边界

提问在资格过滤后，对同一向量索引中的全部合格资料片段做本地 embedding 和余弦相似度召回。集合同时包含一般资料、已标记的个人资料与合格的旧迁移记忆；不按页面或来源先排除任何一类，也不强制每类占据名额。问题原话不必出现在正文中。精确编号边界和相关性排序可作为必要辅助，但关键词包含或标题命中不能成为问答主路径。

沿用 S2 两阶段契约：余弦相似度负责召回候选，不能直接当“有答案”阈值；本地证据复核须判断问题对象、属性、事件、关系、批次和限定语是否由片段支持。已知 S1 单一余弦阈值误放难负例、S2 两候选和 S2R1 均失败；本草案不宣称现有模型已经满足该契约。无经校准的复核能力时自然语言问答保持 `calibration_required`，独立精确查找仍可用。全部候选均不合格时明确显示资料不足，不把相关片段或高余弦自动作为答案。

结果和最终回答必须显示来源类型（一般资料、个人标记资料、旧记忆迁移资料）、资料标题、原始资料标识和可打开的片段。若同一事实有互相矛盾的合格来源，不静默选择个人记忆或最新一条；显示冲突及各来源，让用户核对。个人记忆标签不赋予真实性优先级。多片段组合推理仍按 S2 探索边界报告，不能把单片段复核结果冒充组合推理通过。

## 3. 隐私与版本

先执行现行资料资格、状态、来源依赖和隐私规则。`privacy=local`、待核对、停用、来源缺失或已删除内容不能进入提问候选、证据上下文、云端预览、确认载荷、历史回答或最终回答；它们只可在授权的本地管理与精确查找界面出现。资料或个人标记变化必须更新内容/资格版本、重建相关索引项并使旧缓存及旧云端确认失效。个人标记变化若不改变正文也不能绕过资格检查。

复核后仍须在每一次 DeepSeek 请求前展示实际将发送的内容、目的及预期结果，等待本次单独确认。恢复“我的记忆”视图不扩大云端发送范围，不能把未选中的个人资料、完整历史或整个个人画像一起发送。

## 4. 验收条件

1. 只在资料收集录入个人自述并标记为个人记忆后，“我的记忆”页出现且可管理同一资料；一般资料不因未标记而退出问答检索。取消标记后资料仍存在，只退出该视图。
2. 旧记忆迁移后在管理页可追溯旧标识、状态、来源和历史；同一内容在资料详情和个人记忆视图只对应一个资料标识、一个索引项，不产生重复命中。恢复旧备份保持幂等。
3. 用同义改写的问题分别命中一般资料与个人资料的目标片段；不能依赖题目词语出现在标题/正文。混合语料库中的全局召回应报告实际排名、余弦分数、来源和版本；不能把单一余弦阈值报告成“可回答”。
4. 错人物、错属性、错关系、错业务编号、计划冒充实际、资料明确无答案和提示注入仍须拒绝；正确否定及带“预计/计划/条件”限定的回答须保留限定。两类资料使用同一质量门槛，不按来源放宽。
5. 只有不合格来源时返回资料不足；同事实资料与个人记忆冲突时显示两条来源和冲突，不给无依据的确定结论。`privacy=local` 不出现在向量问答上下文或云端预览。
6. 资料更新、停用、隐私收紧、删除和个人标记切换后，旧检索结果、缓存和云端确认失效；旧回复不得覆盖新状态。逐次云端确认用实际载荷验证。
7. 只有本地语义召回、证据复核、最终回答、浏览器全链路、资源预算与独立审计均在同一固定版本通过，才能讨论解除 `calibration_required`；本草案本身不是验收证据。

## 5. 待用户确认的唯一范围点

建议采用“个人记忆是资料的管理视图”方案。它满足两类内容一起检索，也保留此前唯一资料收集入口和单索引的简洁性。若用户希望个人记忆重新成为独立录入/独立存储实体，则需重做迁移、备份、双来源资格和索引一致性设计，不能由这份草案隐含批准。确认后产品再将本草案转为现行规格并给开发、测试、审计明确交接。
