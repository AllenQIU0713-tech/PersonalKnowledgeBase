# 语义复核不达标时的人工辅助检索备用目标

日期：2026-10-18（Asia/Shanghai）。状态：用户已明确授权的条件降格路线。用户原话：“如果验证继续不通过，则对目标进行降格，不要求检索返回的片段完全贴合提问，可以把相关项都返回，由人工判断最贴切的片段。”

## 1. 条件与目标

当前已在准备的固定批次按原预期继续，历史失败/未执行不改标。若后续真正的语义贴合度、可回答性或本地复核质量仍未达标，后续可交付目标切换为**人工辅助语义检索**：本地系统负责找到并排序相关资料，用户负责阅读并判断哪条最贴切。不再以“所有返回片段均能回答问题”或“第二个本地模型通过可回答性质量门槛”作为该目标交付前提。

HTTP协议不一致、测试工具错误、界面未显示必需信息，以及隐私/来源/删除/版本错误仍按各自缺陷处理；不能通过降格把它们改成通过。当前double只证明接线，不证明真实语义质量，也不必仅为决定备用路线而新增下载或模型实验。

触发条件固定为一次已有或下一次获准的、固定真实reviewer配置在运行前冻结质量门槛上的独立审计失败。现有 `docs/audit/S2R1-ccdd35f/failed-gate-review.md` 已核实提交 `ccdd35f664faf8bbf10929f9ba92208f8ad30bb4` 的真实Q4复核配置为10/15、未达到15/15，包含错对象和计划/条件误放。因此现有证据已足以支持启动人工辅助检索交付准备，无需再下载Q6或新增实验以“证明失败”。此引用只说明该固定配置失败，不推断所有模型或量化不可用。

若总负责继续一次已获准的真实质量验证，其首次硬门槛失败即停止该质量批次并走人工辅助检索交付，不继续迭代以延后降格。接口码/工具故障不属于上述质量触发证据。人工辅助检索可以先完成同版UI/隐私等必要验证；自动问答保留为未达标或后续独立目标。

## 2. 最小产品范围

优先复用已存在的本地语义查找，不新增“我的记忆”录入入口、第二个索引或自动学习模型。收集资料与迁移记忆仍进入同一物理索引，本地embedding与真实余弦负责召回/排序；不得改为关键词包含检索或静默回退。

结果展示多个相关候选，允许间接相关、可能有用但不足以回答的问题片段，以及互相冲突的原文。用户可结合标题、资料标识、来源、状态、原文和相似度/排序自行判断。相似度表示相关程度，不标为答案正确率，不把候选描述为已核实答案。

“相关项都返回”指尽量保留可供人工判断的相关候选，不因缺少答案属性或复核不通过而隐藏它们；不等于一次把全库所有片段返回。首版沿用现有有界结果上限与排序，明确返回范围；不为本次降格新增无限返回/分页机制。若实际使用表明上限妨碍查阅，再按独立需求调整。

该目标承诺辅助回忆和定位资料，不承诺系统自动生成可靠答案或建议。正式QA的未合格状态继续如实显示；不将检索候选放进现有“已通过复核的可发送证据”结构来伪装问答恢复。

## 3. 不随降格取消的边界

- 保留 `collected` / `legacy_memory` 来源追溯、原文与内容/资格版本。允许本地浏览的local、待核对和停用资料继续醒目标记；删除、来源失效及悬空旧片段仍不可返回。
- 本地检索不调用DeepSeek。人工判断不自动触发外发，也不自动产生现有正式QA票据；任何实际云端请求仍须先展示实际载荷、用途、预期结果、模型/目的地并逐次确认。本次条件降格不修改既有云端候选资格规则。
- embedding/索引不可用仍明确暂停，不以关键词结果冒充语义结果。资料浏览与正式问答保持独立状态。
- 仍须验证实际页面交互、结果可追溯、来源/版本正确及隐私/删除/故障边界；真实提供方与未合格模型能力不冒报通过。

## 4. 验收与任务安排

人工辅助检索验收关注同一索引两来源真实语义召回、多个候选及透明排序、人工阅读所需信息、同版UI/HTTP和数据生命周期边界。固定合成题可继续用于回归，但不要求每个返回近邻完全贴合问题；不充分答案或冲突原文作为相关浏览候选本身不构成该模式失败。

旧4e问答九失败保留为旧正式QA门禁失败，不能追溯改为通过；391/afa的后端门禁和新HTTP验证继续按原范围记录。总负责在本轮结果复核时按本条件路线决定后续交付范围，无需再次就用户已授权的目标降格征求同一许可。

Q6/第二复核模型仍可独立研究，但不再是人工辅助检索的必要依赖或上线门槛；所有既有下载、构建、资源授权及来源审计阻断继续有效。不得为达成该备用目标自动触发新的Q6资源申请。
