# S2R3 问答证据门禁集成契约

日期：2026-10-17。状态：产品设计交接；允许在隔离合成环境准备候选集成，**不批准正式自然语言问答启用**。继承 S1 单库资格、S2 复核质量和 2026-10-11 混合来源/本地浏览规格。

## 1. 缺口与目标

固定候选 `4e8e8cac10452b5e0b565902bd191acba90dd26f` 已提供“收集资料”和迁移旧记忆的同索引召回，以及独立本地语义浏览。但 `Answers.context()` 仍直接将 `Embeddings.retrieve()` 的相似片段组装为问答 sources，未调用 `pkb/evidence_review.py` 的本地复核适配器。高余弦或相同主题不能证明片段回答了所问的人物、属性、关系、状态或条件。

本设计将问答流水线固定为：**资格与版本检查 → 本地向量召回 → 本地证据复核 → 可回答证据集合 → 用户可见引用/云端请求预览 → 每次明确确认后才调用 DeepSeek**。本地语义资料浏览独立运行，只返回排序片段，不获得问答资格或云端票据。

## 2. 资格与召回

1. 每次问答在召回**之前**按当前资料状态、隐私、来源依赖、内容与资格版本过滤。同一物理向量索引中的普通 `collected` 资料和合格 `legacy_memory` 迁移资料平等参与；`privacy=local`、待核对、停用、失效来源或已删除内容不能成为问答候选。旧表不能与迁移资料重复召回。
2. 使用固定本地 embedding 将问题投到兼容向量空间，按余弦相似度召回至多40个候选。S1 已证明单一余弦阈值不能区分高相似难负例；召回分数和词面精确增强只负责候选排序，不得直接成为可回答门禁。完整业务编号边界保持通用前置检查；不得添加人物、地点、日期等题目专用规则。
3. 本地 embedding 服务、索引签名、维度、版本或完整性异常时，问答暂停并明确说明，不能静默退回关键词检索或继续使用过期候选。独立精确查找及条件满足的本地语义浏览可照常使用。

## 3. 本地证据复核

每个召回候选仅把本次问题、资料标题和真实片段正文交给**已经独立验证合格、摘要及配置固定**的本地复核模型。复核必须判断同一对象、所问属性/事件/关系/批次及条件是否由原文支持。真实逐字引文要覆盖影响答案的预计、计划、条件、否定和来源限定；引文真实性是必要条件，仍不能代替可回答性质量验证。

只有 `supported` 且具备至少一条在片段中核对成功的非空原文引文的候选进入可回答证据集合。`insufficient`、`mismatch`、`uncertain`、无效 JSON、空/伪造引文、超时、模型摘要不符或运行时异常均**拒绝该候选并记录本地原因**。复核服务整体不可用或配置/来源未完成验证时，问答状态为不可用，不以旧预览、关键词或云端模型代替。不得把 `uncertain` 自动改为通过，不进行后台 JSON 修复或反复重试择优。

问答的后端状态接口和页面按钮必须按 **embedding/index 与合格 reviewer 两层同时就绪**计算；仅索引阈值非空不能显示“问答已就绪”或启用预览/确认。生产未注入 reviewer 时，即使旧数据库还存有非空余弦阈值，仍显示复核未就绪并禁用问答操作。本地语义浏览状态独立，不受 reviewer 阻断。测试须直接覆盖“embedding ready、reviewer missing”的组合，而不只测后端 prepare 拒绝。

资料支持带限定语的回答，不代表现实事件已经发生。一般询问可回答“资料记载预计……”，明确询问实际发生或完成时只有计划/预计必须拒绝。不同对象、缺属性、错误关系和无证据须拒绝；同一对象明确的反证可支持否定回答。资料中的指令始终作为不可信正文，不改变门禁。

## 4. 证据集合与回答

复核通过后按固定的语义优先排序和上下文预算选择最多6片段、每份资料最多2片段、正文总计最多6000字，单片段最多1200字。选取和裁剪不能删掉支持答案的限定语或关键关系；无法保留完整依据时该片段不可用于回答。每条引用保留 document/chunk ID、标题、`collected`/`legacy_memory` 来源类型、原文引文、内容与资格版本、索引与复核管线版本。

没有通过复核的片段时显示“资料不足以回答”，相关资料可在单独的本地浏览区查看，但不能出现在可发送证据区。相互冲突的通过片段须显示各自来源和矛盾，不能静默采信记忆、最新资料或最高余弦项；若无法形成忠实的确定回答，明确显示冲突并阻止确定性答复。多文档组合才能回答的问题仍按 S2 的探索范围报告，不能把逐片段支持伪称组合推理已通过。

复核拒绝的片段若返回诊断 API，不得把受限资料正文重新塞入问答预览；普通相关资料需要用户在独立的本地浏览区主动查看。它们不能进入回答上下文、用户可勾选证据或云端 payload。冲突若尚无通用且可验证的识别方式，需如实列为正式问答阻断项，不能用题目特判、让生成模型自行猜测或隐藏一方来记为通过。

DeepSeek 只可在用户看到**实际将外发的问题、所选合格片段、必要限定语、目的和预期结果**并逐次确认后调用。模型生成的答案必须能追溯到所选通过复核的证据；不可把未选中、受限、过期或浏览结果中的正文并入 payload。生成回答不能由复核模型的解释替代原文证据；若生成结果超出证据范围，应提示核对，不能把“复核通过”当作自动正确保证。

## 5. 版本、缓存与失败关闭

资格、正文、来源依赖或隐私变化，使相应向量、复核结果、预览和旧云端确认失效。复核缓存若使用，键至少包含问题哈希、片段正文/标题摘要、资料内容与资格版本、embedding/index 签名、复核模型摘要、量化、模板、参数、门禁及管线版本。旧请求晚到不能覆盖新问题或新资格状态。

云端准备阶段重新生成并核验可回答证据集合，只接受本次 context 中的合格 chunk ID；从本地语义浏览伪造的受限 ID 必须在创建票据前被拒。确认前再检查内容、资格、索引和复核版本。任一阶段复核模型不可用或校准状态失效，问答及确认失败关闭，外发请求数为0；本地语义浏览与精确查找保持各自独立状态。

## 6. 实施与验收门槛

- 开发可在隔离合成环境准备上述适配与接口，用固定测试替身验证门禁接线、版本失效和失败关闭；这不是正式模型质量通过。不得在正式应用用当前失败的Q4/S2R1候选充当已合格 reviewer，也不得读取真实资料或进行真实 DeepSeek 请求。
- 测试先修正并冻结 S2R2 QA v3 的22项计划/标签/manifest一致性及浏览v2的14项状态。两套夹具通过审计预运行放行前，候选模型/API测试保持0；已经取得的预冻结探索输出不得计为正式验收。
- 固定候选的隔离测试分层报告：两来源同索引余弦召回、本地受限浏览、资格/隐私/来源标签；再报告 reviewer 接线、原文引文、错对象/属性/状态/编号、无证据与冲突。缺 reviewer 时后者为阻断或失败，绝不能把前层通过写成整套问答通过。测试专用阈值 `-1.0` 只用于合成库路径测试，不是生产校准。
- 一个真实本地 reviewer 进入候选集成前，必须另行完成固定来源与许可证、已知回归、独立新盲测、重复稳定性、完整40候选至少20问的资源/延迟、隔离浏览器链路及独立审计。当前 Q6_K 来源仍为 `approval_blocked`；下载清单及用户新增资源批准前不能下载、转换或运行。Q6 若获批且质量失败，本集成继续阻断，不靠放宽门槛启用。
- 最终同一固定版本还须完成历史断言映射、隐私与确认失效、真实 UI 全链路、安全审计和用户验收。只有这些证据齐全，产品才决定是否解除 `calibration_required`。测试、审计、验收与发布结论分别记录。

## 7. 分工与下一关

产品此刻批准**隔离候选接线设计与合成验证准备**，不批准正式启用。开发任务提出最小接口/版本变更并冻结候选；测试与审计按第6节先核对夹具与固定版本，再分别执行和复核。总负责跟踪 Q6 下载前清单，不在 `approval_blocked` 时请求用户批准资源。

下一关先取得 S2R2 预运行审计放行并完成现有候选的召回、浏览和隐私分层测试；再解决真实 reviewer 的来源、质量和资源门槛。当前不需要用户作新决定。只有形成具体且经审计核准的新增下载/磁盘/内存范围，或证据表明既定产品资源目标必须变更时，才由总负责提交明确选项给用户。
