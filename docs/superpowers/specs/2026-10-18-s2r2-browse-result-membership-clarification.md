## 1. 适用语义

本地语义浏览在有效浏览资料集合内按本地向量余弦排序，返回有限数量的近邻。它不判断资料是否足以回答问题。删除某条资料或撤销其必要来源后，其他仍有效的资料可以继续作为近邻返回；不能仅因本题目标失效而要求整个浏览 API 的 `items` 为空。

依据为 `2026-10-11-unified-source-semantic-retrieval-clarification.md` 的本地语义浏览、删除及来源撤销不得出现悬空片段、与问答资格隔离等规则。服务/索引故障仍须明确未就绪，不属于本记录的正常近邻结果情形。

## 2. 正负例的统一计分

- 正例 `expected_results=[目标...]` 表示目标必须出现在冻结查询范围/返回上限内，且来源类型、状态标签、相似度/排名等既定断言成立；不是要求完整 `items` 与该列表相等。其他有效近邻可保留。
- 失效负例的空列表表示该用例目标投影为空，即本题被删除或来源失效目标的全部实际映射 document/chunk 均不可出现在结果中；不是全库近邻必须为空。其他有效近邻仍须满足正常浏览资格、来源与版本规则。
- 测试必须检查原始完整 API 输出，然后按冻结 fixture→实际 document/chunk 映射判定目标存在/不存在；不能先过滤不合格项再计分。其他已删除、来源缺失/撤销或旧版本悬空片段若出现，仍应记真实失败。
- 查询语义正例、零共同登记关键词、真实余弦分数及排序、失效/缓存/问答边界的原有断言均保留。不能用“其他近邻允许”掩盖目标未召回，也不能将近邻列表当作可回答证据。
