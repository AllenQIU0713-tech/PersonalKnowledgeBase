# 个人知识库第一版设计

状态：产品设计已由用户确认，可以进入开发实施阶段。

版本：V1.1。初次确认日期：2026-09-24；2026-09-25 用户确认 DeepSeek API 与逐次云端调用确认规则。

角色约定：本任务「设计本地个人知识库」负责产品设计和需求决策；实施计划、技术选型、代码开发与开发验证由任务「实施产品设计方案」负责。本文件是第一版产品范围与验收依据，不代表开发已经启动或完成。

## 已确认需求

- 使用设备：macOS，M5 芯片，24GB 内存，1TB 硬盘总容量；剩余空间尚未检查。
- 第一版仅在这台 Mac 上使用。
- 原始资料、向量索引、检索和个人记忆保存在本地。
- 使用本地小型文本向量模型，通过外部模型完成问答与复杂理解。
- 支持收集文字、图片和其他媒体，帮助回忆历史并提供有历史依据的建议。
- 尽量减少云端交互，允许查看、纠正和删除个人记忆。

## 路线选择

选择本地检索加云端回答。相比云端处理全部入库资料，减少外发内容；相比每次手动选择资料再调用云端，保留自动检索与上下文组装能力。

## 使用界面

采用本机浏览器界面，由仅监听 127.0.0.1 的本地服务提供，无需公网托管或知识库云端账户。外部模型服务可能需要独立账户与凭证。服务需校验来源和本机会话凭证，防止其他网站借浏览器调用本地接口。第一版不提供局域网访问或远程同步。

三个主要入口：

1. 收集：粘贴文字、拖入文件、粘贴剪贴板图片；可填写标题、标签和隐私级别。
2. 查找与提问：关键词与语义混合检索，直接查看原件；需要综合回答时调用外部模型。
3. 我的记忆：查看偏好、目标、经历和待确认记忆，支持确认、修改、失效和删除。

## 本地数据与处理

- 原件按稳定标识保存，数据库记录来源、导入时间、用户提供的事件时间、类型、哈希及处理状态。用户原始路径不是唯一副本。
- 元数据、全文索引、向量索引、聊天记录、个人记忆及外发记录留在本机。数据库与索引的具体实现由实施计划确定。
- 文本分块保留文档、页码或段落位置，供检索结果和回答引用。
- 使用本地文本向量模型；Qwen3-Embedding-0.6B GGUF 为候选，先验证中文检索质量、运行时兼容性与资源占用，再确定版本。
- 入库与查询采用匹配的向量模型和配置，记录模型版本；更换模型需要重建向量索引。
- 后台处理限制并发，显示进度，支持失败重试。首次模型下载需要联网，日常文本索引无需联网。
- 数据目录默认选择不在 iCloud Drive 同步范围内的应用支持目录；初始化时明确展示位置。不得声称能阻止用户另行配置的系统备份或第三方同步。

## 第一版媒体范围

- 文字、Markdown、纯文本文件：直接提取、分块、索引。
- PDF：提取文本并保留页码；扫描页面进入本地 OCR 流程。
- 图片：保留原件，尽量通过 macOS 本地 OCR 提取文字；照片中的场景和语义理解属于单独的云端操作。
- 音视频及尚不支持的文件：允许收集、命名、标注和找回原件，明确标记尚未解析正文；第一版不承诺自动转录或视频理解。
- 无法解析的资料不会被静默丢弃，也不会被声称已经具备内容检索能力。
- 第一版不自动抓取网页链接或导入外部账户，避免隐藏网络请求。

## 已确认的外发规则

隐私级别必须同时作用于原件、提取文本、分块、记忆、聊天上下文及引用预览。

- 默认资料：用户点击“生成回答”或“给建议”只启动本地准备流程，不立即请求云端。必须先展示本次实际外发内容、处理目的与预期结果，经用户单独点击“确认发送给 DeepSeek”后，才允许发送当前问题、必要聊天上下文、相关片段及必要的已确认记忆。每次云端模型请求均需确认，不提供永久同意或后台自动授权。
- 禁止外发：只用于本地搜索和查看，不进入云端提示词、附件、历史消息或派生记忆。系统说明这些资料未参与云端回答，但不能把资料标题或摘要通过提示词泄露给云端。
- 云端图片理解：由用户针对图片主动触发，展示实际将发送的图片或选区、附带文字和预期结果，再单独确认。优先本地 OCR；文字足够时不上传原图。图片能力以所接入 DeepSeek 官方模型的实际支持与账户权限为准，不支持时明确提示并保留本地 OCR 与手动整理，不自动切换其他供应商。禁止外发资料不能触发此操作。
- 默认不在后台调用云端模型整理全库，不上传完整资料库、完整对话历史或完整个人档案。
- 敏感信息检测只能辅助提醒，不能被视为保证脱敏；隐私级别和实际出站内容过滤是主要控制。
- 用户已选择 DeepSeek 官方 API，通过可替换的服务适配层接入，不使用未授权中转服务。凭证由用户在本机受保护配置或环境变量提供，不在聊天中索取、显示或转发，不写入项目文件、前端、普通日志或普通数据备份。配置密钥不等于授权发送资料，真实调用仍遵守逐次确认规则。
- 出站记录保存时间、用途、服务和发送片段标识，正文不重复持久化；删除资料时清理关联记录。第三方已经收到的数据无法通过本地删除保证撤回。

## 回忆、回答与个人记忆

- 搜索同时使用关键词、语义相关性及可选的时间与标签过滤，支持查找原句和模糊描述。
- 回答以检索到的资料为依据，引用可点击回原始片段。缺乏证据时明确说明，区分历史事实、个人偏好和建议。
- 导入资料作为数据处理，不执行资料中要求改变规则、调用工具或外发内容的指令。
- 用户可手动添加记忆；云端回答流程可以附带提出记忆候选，但必须在本次确认页的预期结果中明确说明，并且只使用该次获准内容。不为生成候选额外后台上传；若需要额外请求，重新展示并确认。
- 模型推测的偏好先进入待确认列表；确认后才能作为稳定偏好参与后续回答。
- 每条记忆保存来源、形成时间、有效状态及修改历史。冲突信息标记出来，不静默覆盖。
- 删除来源时，关联分块与向量删除，派生记忆删除或重新由剩余来源验证，关联聊天引用及含该资料内容的已存回答一并提供明确清理机制。

## 失败、备份与边界

- 断网或模型服务不可用时，收集和本地检索继续工作；回答失败可重试，不伪造结果。
- 首次下载模型失败时仍允许保存资料和关键词检索，明确提示语义检索尚未启用。
- 导入前检查文件和可用磁盘空间；限制单文件和批次处理资源，索引失败保留原件及原因。
- 提供本地导出备份与恢复流程；备份包含原件、结构化记录和重建索引所需版本信息。备份不会因实时数据库删除而自动消失，恢复时必须应用删除记录，避免已删内容重新进入检索。
- 第一版不自动执行建议、代发消息、访问个人外部账户或持续监控桌面。
- 应用不默认启用遥测，不加载远程字体或分析脚本；维护下载与问答流量分开呈现。

## 实施顺序与验收

1. 验证本地运行环境、剩余空间和向量模型，使用人工构造样本测试中文检索；未经明确操作，不把真实个人资料用于云端测试。
2. 完成文字、文件、图片的本地收集、解析状态、全文与向量检索。
3. 完成云端出站过滤、带来源问答、外发记录以及禁止外发测试。
4. 完成个人记忆确认、纠正、失效和关联删除，验证备份恢复。

验收覆盖：断网下入库与搜索；中文模糊查询；PDF 页码定位；解析失败可见；禁止外发资料在新问答及历史上下文中均不出站；来源删除后不再被检索或通过记忆复现；模型失败保留用户输入；备份恢复可用且尊重删除记录。

### V1.1：DeepSeek 与逐次外发确认

用户原始要求：“云端模型我使用deepseek 的api，在使用系统时，如果遇到需要调用云端模型的场景，需要我的确认，并且告诉我会把什么送到云端模型，并且希望得到什么结果”。本节是可执行产品变更，交开发、独立测试与审计执行。

#### 用户流程

1. 本地准备：检索、OCR、筛选与脱敏均在本地完成。准备确认页不能依赖云端请求。
2. 展示确认页：说明为什么需要云端；显示 DeepSeek、具体模型和实际接收服务地址；列出本次问题、历史消息、资料片段、个人记忆及附件。每一项可查看完整的实际发送内容，禁止仅用“相关资料”代替。固定任务指令与输出要求可展开查看；密钥和认证头不显示。
3. 说明预期结果：例如“基于所选资料生成带出处的回答”或“从以下 OCR 文字中提取航班号、起降地点及时间，返回待核对字段”。描述目标，不保证模型正确或承诺达到结果。
4. 提供“取消”和“确认发送给 DeepSeek”。用户可排除片段；如支持编辑或脱敏，必须更新实际请求预览后再确认。取消、关闭或未确认均不发送，继续允许本地使用。
5. 发送与记录：仅发送已确认的请求；完成后在本地记录用途、模型、时间、来源标识、确认关联及结果状态，不为日志重复保存敏感正文。
6. 结果处理：回答标注来源与模型生成属性；提取出的字段和候选记忆先供核对，再保存为确认的结构化记忆。

#### 确认的有效范围

- 后端必须验证一次性确认凭据与实际请求匹配，不能只靠前端弹窗。确认绑定本次内容、附件、用途、模型和接收地址，不能复用来执行后续请求。
- 资料内容、隐私级别、选择的片段、模型或接收地址变化后，旧确认失效。发送前再次检查禁止外发与资料删除状态，发现变化则重新准备并确认。
- 一次确认对应一次模型请求；不隐藏额外摘要、修复 JSON、备用模型或重试请求。失败或超时后可由用户查看内容再次确认重试；提示上次超时不代表供应商未收到数据。
- 真实连通性测试、后台整理及模型触发的工具行为不能绕过外发确认。测试优先采用模拟服务；真实模型测试也须展示合成内容并获得该次确认。
- 已确认发送后再关闭页面不能撤回供应商已收到的数据；界面区分发送前取消与发送后停止等待。
