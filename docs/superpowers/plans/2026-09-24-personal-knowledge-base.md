# 个人知识库 Implementation Plan

**Goal:** 在本机提供可持续积累资料、检索与带来源问答的知识库。

**Architecture:** Python 标准库本地 HTTP 服务与 SQLite 持久层；原件独立存储，浏览器只访问同源 API。macOS Vision/PDFKit 负责本地媒体文字提取；独立本地向量服务通过适配层调用。云端适配与本地检索分离，出站前重新检查隐私与来源。

**Tech Stack:** Python 3.9+、SQLite、原生 HTML/CSS/JavaScript、Swift Vision/PDFKit、候选 Qwen3-Embedding-0.6B GGUF / llama.cpp。

**Spec:** `docs/superpowers/specs/2026-09-24-personal-knowledge-base-design.md`

## 全局约束

- 仅绑定 127.0.0.1；校验 Host、Origin、会话及 CSRF 凭证。
- 默认目录位于 ~/Library/Application Support/PersonalKnowledgeBase；测试使用独立目录。
- 原件、数据库、索引、记忆、聊天及外发记录本地保存；无遥测、外部字体、自动网页抓取。
- 禁止外发覆盖派生数据和历史；后台不调用云端。
- 供应商及凭证未选择，真实云端调用保持禁用；模拟适配明确标识。
- 原件解析失败必须保留并显示原因；不把未解析或未向量化标为成功。
- 测试版本固定，开发不得改变测试工作区或数据。

## 模块与边界

`pkb/config.py`：目录、限制与配置。`pkb/store.py`：SQLite、资料/分块/删除记录。`pkb/server.py`：HTTP、请求验证、路由。`pkb/static/`：三入口界面。`pkb/extract.py` 和 `scripts/extract.swift`：有限并发媒体解析。`pkb/embedding.py`：本地向量配置、索引、检索。`pkb/answers.py`：外发预览、过滤、模拟问答及引用。`pkb/memories.py`：记忆及来源。`pkb/backup.py`：备份、恢复及删除记录。`docs/deliveries/`：逐批交付说明。

## 界面实现约定

使用 frontend-design 技能：主题为私人资料柜，灰蓝背景 #edf1f5、白纸 #ffffff、深墨 #243445、主色 #345c8c、淡蓝 #dce7f4、错误色 #a53c43。系统苹方作为正文、系统宋体只用于页面标题、等宽字用于时间。左侧固定三个入口，中间资料列表，右侧原文阅读区域；窄屏纵向排列。资料卡的来源/时间/隐私条是主要辨识元素。无远程资产；所有用户正文通过 textContent 呈现。
