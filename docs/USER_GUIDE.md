## 启动与首次打开

日常可直接双击项目根目录`启动知识库.command`，无需逐次输入下面两个终端命令。它启动现有Embedding和应用并自动打开浏览器，按Ctrl+C停止本次自有服务。端口占用时先退出，不结束其他程序。首次执行会使用下述默认正式目录，需确认资料目录。以下手工命令保留用于排障、指定目录或已有自有模型服务的场景。

使用两个终端窗口，分别保持模型服务和知识库服务在前台运行。先结束占用相同端口的本项目自有会话；若端口被其他程序使用，先确认归属，不要结束无关进程。

终端一启动现有本地向量模型：

```sh
/opt/homebrew/Cellar/llama.cpp/0.5.0/bin/llama-server \
  -m "/Users/allenqiu/Library/Application Support/PersonalKnowledgeBase/models/Qwen3-Embedding-0.6B-Q8_0.gguf" \
  --embedding --pooling last -ub 8192 -c 4096 -np 1 \
  --host 127.0.0.1 --port 8766
```

这是现有获准模型的位置，不需要另行下载或安装。已核对文件存在、大小为 639,150,592 字节；本次未重新计算模型摘要。预期 SHA256 为 `06507c7b42688469c4e7298b0a1e16deff06caf291cf0a5b278c308249c3e439`。如交付前文件被替换或路径失效，应重新核对既有模型与运行时身份，不自行改用其他模型。

终端二进入项目并启动知识库：

```sh
cd "/Users/allenqiu/Documents/ChatGPT/个人知识库"
/usr/bin/python3 -m pkb.server \
  --data-dir "/Users/allenqiu/Library/Application Support/PersonalKnowledgeBase" \
  --port 8765 --embedding-port 8766 \
  --embedding-model 06507c7b42688469c4e7298b0a1e16deff06caf291cf0a5b278c308249c3e439
```

上述 `--data-dir` 是实际默认资料目录。启动会打开该目录，并可能执行旧资料迁移和建立索引，不能把这条正式目录命令当作隔离测试命令。UAT已经通过，但本次收尾没有执行这条正式目录命令；重新测试时使用独立的合成目录。

在终端二找到“请用浏览器打开（一次性链接）”，把**本次完整链接**粘贴到浏览器地址栏打开。链接含本次启动凭证，不要转发或放进截图、文档。若显示“本机知识库安全入口”，点击一次“继续打开本机知识库”即可；首次403是保留的安全校验，不需要改请求头或浏览器设置。随后进入 `http://127.0.0.1:8765/`，同一浏览器会话可继续使用。

不要重复打开一次性链接；已经进入应用后使用主页地址。若确实提示启动链接已失效且尚未建立可用会话，停止并重新启动知识库以取得新链接。重启会使旧会话失效。普通使用不需要开启远程调试或点击调试 Allow。

数据、原件和索引保存在指定本机目录。页面只监听 `127.0.0.1`。本路径不需要设置 DeepSeek 密钥，也不启动第二个复核模型。

## 查找和比较原文

1. 打开“查找与提问”，在“本地语义查找”中用自然语言描述想找的内容，点击“语义查找”。等待语义服务和索引就绪；“基于资料提问”的校准/复核未就绪不等于本地语义查找不可用。
2. 比较返回的多个候选。每次最多 20 个片段，每份资料最多 2 个，卡片摘录最多 400 字；这是有界候选集，不代表穷尽全部相关资料。余弦分数用于排序，不是答案正确率。间接相关、信息不足或互相矛盾的片段仍需由你判断。
3. 查看标题、来源、文档/片段编号、版本和状态，点击候选，在资料详情中定位并突出显示对应完整原文片段，再返回比较其他候选。受限资料保留本地查阅标签；点击和选择仅用于本地阅读，不产生回答、云端请求或外发资格。
4. 已知标题、原文关键词或完整编号时，使用单独的“精确查找”，也可加标签和日期筛选。语义服务暂停时可继续精确查找；应用不会暗中用关键词结果冒充语义结果。

保存修改、调整隐私/旧记忆状态、删除或重试解析后，按页面提示重新语义查找，不继续依赖旧候选。其他窗口或接口造成的变化没有实时推送，下一次查找或点击候选时会重新核对；遇来源失效、删除、版本变化或读取失败，应重新查找。索引或语义服务故障时查看暂停提示，保持精确查找与语义查找分开使用。

“基于资料提问”仍受独立校准和证据复核门禁限制，本次人工检索交付不解除该限制。不要通过修改阈值、伪造复核就绪或调用测试替身启用问答/云端发送。

## 停止与下次使用

先在终端二按 `Ctrl+C` 停止知识库，再在终端一按 `Ctrl+C` 停止本次启动的向量模型。关闭网页不会停止后台服务；不要用结束所有 Python/Chrome/模型进程的方式停止。资料和索引保留在本机，下次仍指定同一资料目录，重新按上述顺序启动并使用新链接。

如只需要精确查找，可不启动终端一；终端二执行以下命令，不传向量模型参数：

```sh
cd "/Users/allenqiu/Documents/ChatGPT/个人知识库"
/usr/bin/python3 -m pkb.server \
  --data-dir "/Users/allenqiu/Library/Application Support/PersonalKnowledgeBase" \
  --port 8765
```

此时语义查找不可用，应使用页面明确标注的精确查找。备份/恢复前也应停止知识库；具体操作见项目 README。
