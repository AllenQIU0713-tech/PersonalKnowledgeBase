# BUG-B4-001 备份 SQLite 日志模式整改

根因：SQLite backup API 得到的一致快照仍保留 WAL 模式，ZIP 仅携带数据库文件，恢复直接只读打开时会尝试建立缺失的 WAL/SHM 辅助文件。

修复：导出独立快照后执行 PRAGMA journal_mode=DELETE，再生成哈希和打包。恢复对已经解压、完整性校验且不会并发修改的临时快照使用 mode=ro&immutable=1，兼容之前带 WAL 文件头但由 backup API 生成的独立快照。不对运行中的数据库使用 immutable，不更改生产数据库日志模式。

状态：修复完成待测试；开发未运行复现或测试。
版本：包含本文的提交，基于 1720d8f，同时包含 AUD-B3-001 重解析前清理与旧数据迁移。

复测：正常导出恢复、旧备份恢复、重复恢复、删除记录合并、原件与记忆/历史关联、损坏备份拒绝、源数据库运行模式未被更改。
