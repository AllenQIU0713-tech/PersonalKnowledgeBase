# B1 开发交付：收集、关键词检索与本机入口

状态：开发完成，可以开始本批次测试；未运行测试，未声称测试通过。

## 范围

- 仅监听 127.0.0.1；Host、Origin、Fetch Metadata、一次性启动链接、HttpOnly/SameSite 会话与写请求 CSRF 校验。
- 文字与文件收集，标题/标签/事件日期/隐私设置；拖放与剪贴板图片选择；每文件 25 MiB、保留 128 MiB 磁盘余量。
- UUID 原件存储、SHA256、SQLite 元数据与文字分块；UTF-8 文本解析失败保留原件并显示原因。
- 关键词、标签、日期检索；原件下载、原文查看、隐私修改、删除与删除记录。
- 原生浏览器界面，用户文本通过 textContent 呈现。

## 启动与版本

测试版本为提交此文档的 B1 提交。请使用该提交的独立 git archive/检出目录及 /private/tmp 下独立数据目录，不在开发工作目录启动测试。

`python3 -m pkb.server --data-dir /private/tmp/pkb-test-B1 --port 8871`

使用标准输出中的一次性链接；GET /api/session 提供 CSRF；POST 使用 application/json、同源 Origin、X-PKB-CSRF。导入 data 为 base64，privacy 为 allowed/local，tags 为字符串数组。

## 测试交接重点

由测试任务执行：离线文字/文件入库、中文原句/标签/日期查找、原件字节一致性、解析失败可见、超限拒绝、跨源与无凭证请求拒绝、XSS 文本显示、隐私切换与删除后检索。

## 本批次限制

PDF/OCR、语义检索、云端问答、个人记忆与备份尚未实现，页面明确显示未启用；媒体当前只能按标题/标签查找和下载。关键词采用本地分块文字匹配，不宣称中文模糊语义能力。当前搜索返回最近匹配的最多 100 份资料。
