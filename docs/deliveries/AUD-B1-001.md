# AUD-B1-001 整改交付

根因：原实现先删除数据库资料，再移除原件；文件系统错误后没有独立清理状态，接口先读取已删除资料导致不能重试。

重新设计：持久 pending_cleanup 队列与 tombstones 同步记录，原件清理单独幂等执行。资料先从检索和下载移除；unlink 失败保持可见清理记录，收集页“原件待清理”支持重试；重启对删除记录重新执行清理。重复删除不依赖资料仍存在。备份恢复应用删除记录时复用清理流程，失败不会回滚已提交恢复记录或删除已恢复原件。

版本：包含本文的整改提交，基于 B4 d23bf69，同时包含 BUG-B1-001 修复。

状态：整改实现完成，交独立测试复测，尚未验证通过。

复测条件：正常和重复删除、unlink PermissionError 后状态可见、不可检索下载、权限恢复后重试成功、重启后继续清理、旧备份恢复不会复活删除内容。请测试任务报告后通知审计逐项复审 AUD-B1-001。
