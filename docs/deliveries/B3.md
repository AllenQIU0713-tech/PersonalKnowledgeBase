# B3 开发交付：隐私过滤与问答模拟

状态：开发完成，可以开始该批次测试；未运行测试。

版本：包含本文的 B3 提交，承接 B2；启动方式不变。

## 范围

预览本次问题的允许片段，最多 6 个/6000 字；禁止外发资料的标题和片段不进入上下文 sources。每次生成时服务器重新检索和检查，客户端不能指定提示正文。历史不外发，避免隐私设置改变后旧历史泄露。离线模拟适配器用于流程交付并在输出和日志明确标识，不伪造模型回答。

保存问答与来源，引用可返回片段；外发记录仅标识不存正文。资料删除或改为禁止外发时清理关联回答和出站记录。图片理解 API 对禁止外发资料拒绝，允许资料返回“服务未配置”，不会发送图片。

## 测试交接

请验证默认/禁止外发混合检索、预览后隐私变化/删除、伪造客户端上下文、同一资料关联回答的删除清理、历史不作为请求上下文、错误时输入保留、离线模拟标识与无网络行为。

真实模型服务及图片理解尚未接入：用户尚未选择供应商与凭证，须后续核实服务条款后配置。这是产品设计允许的接入前限制，不能将模拟结果标为真实云端问答验收通过。
