# S1 单一资料库语义检索校准候选交付

日期：2026-10-01
产品契约：`docs/superpowers/specs/2026-09-30-single-library-semantic-retrieval-design.md` S1
状态：开发阶段校准候选，等待独立测试测量阈值；不是最终候选，不代表测试、审计、用户验收或发布通过。

## 解决的问题

用户连续遇到“资料存在但自然问法找不到”的问题，旧实现又在资料与个人记忆之间建立了两套入口和两条召回路径。S1 不再继续添加中文词面特判，而是把所有输入统一为资料，用一套固定、版本化、失败关闭的本地语义索引处理自然语言问题。

## 实现范围

- 页面只保留“收集”和“查找与提问”；运行时不实例化旧 `Memories`，正常 HTTP API 不再提供个人记忆 CRUD。
- 旧个人记忆在服务暴露前确定性迁移为文字资料。迁移前创建本地 ZIP，保留原文、主题、时间、状态、隐私、来源、冲突、历史、旧标识与映射；重复启动不重复生成。
- `document_metadata` 与 `document_sources` 统一管理提问资格。local、未解析、待核对、停用、冲突、缺失/受限来源和循环关系均在向量索引前排除。
- 新 `semantic_vectors` 和 `semantic_index_config` 绑定片段、来源哈希、内容/资格版本、固定模型、段落/查询模板、池化、维度、索引代次、校准报告和阈值。
- 固定模型为 Qwen3-Embedding-0.6B Q8_0，SHA256 `06507c7b42688469c4e7298b0a1e16deff06caf291cf0a5b278c308249c3e439`；仅允许 `127.0.0.1`，禁用代理与重定向。
- 自然语言路径只有在服务、完整兼容索引和真实模型校准全部就绪后开放。没有关键词回退；精确资料查找始终独立可用。
- 排序先取达到阈值的语义前 40 个候选，只在其中按完整业务编号、标题、标签和完整日期增强，使用 S1 固定 RRF，稳定返回最多 6 个片段、每份资料最多 2 个。
- 新问答、离线模拟、云端 payload、确认绑定和外发标识只使用资料片段。确认同时绑定片段内容/资格版本、索引签名/代次/修订/阈值和请求摘要。
- 备份恢复保留迁移映射与旧只读兼容表，不信任归档向量；旧格式记忆恢复后走同一迁移器。
- 提供 `python3 -m pkb.calibrate measure|apply`，记录数据集哈希、固定配置、全部原始余弦分数和报告哈希。

索引格式：`single-library-passage-v1` / `qwen3-query-v1` / pooling `last`。
云端上下文格式：`single-library-v1`。
迁移版本：`S1-single-library-legacy-memories-v1`。

## 当前有意保持的阻断

代码中没有猜测默认余弦阈值。新库或配置变化后会停在 `calibration_required`，因此这个提交不能作为自然语言功能的最终验收版本。独立测试须先用真实固定模型测量并选择阈值；开发收到证据后再把阈值和报告哈希固化到新提交，并交完整复测。

若一个阈值无法同时满足 S1 正例与难负例，测试应提交原始分数与失败样本。开发保持自然语言不可用并反馈产品，不加入问题特判、不修改验证标签、不静默放宽要求。

## 独立测试交接

测试请绑定开发通知中的不可变提交，并使用独立检出、数据目录和端口。必须覆盖：

1. 按 S1 第 9 节使用未参与开发调试的校准集测量真实 Qwen 模型，保存数据集、原始分数、配置、报告 SHA256、阈值依据和失败样本。
2. 用另一组独立验证集验证同一阈值；正例、无答案、相同实体不同属性、近似亲属/项目/编号与边界样本均不能用开发夹具替代。
3. 原始蓝鹭资料、四种生日问法、旧生日记忆迁移、不合格旧记录、来源收紧/删除/修改、备份恢复、幂等重启和确认失效。
4. 服务中断、错误维度、索引不完整、模型/模板变化、校准缺失时自然语言阻止；精确查找仍能按标题、原文和完整编号工作。
5. 单一 UI/API 入口、迁移详情、浏览器全链路、离线模拟、云端确认取消，以及新记录只引用资料片段。
6. 显式给出旧 159 项的保留、等价更新、按新范围退役和新增映射，不机械沿用旧“个人记忆”界面断言。
7. 网络只允许本地 UI 与固定回环嵌入服务；不得下载模型或访问外网；`cloud_requests` 不增加，不发送真实 DeepSeek 请求。

完整命令和校准 JSON 格式见 `README.md`。
