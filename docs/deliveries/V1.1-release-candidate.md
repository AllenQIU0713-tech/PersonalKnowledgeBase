# 本地个人知识库 V1.1 完整开发交付候选

状态：开发范围完成，等待同一最终版本的整体测试、浏览器实机验收与最终安全合规审计。本文件不声明已发布或用户已验收。

日期：2026-09-26。

## 已实现范围

### B1：本地资料库

- 仅监听 `127.0.0.1` 的本机 Web 服务，一次性启动链接、本机会话、Origin/Host/Sec-Fetch-Site 与 CSRF 校验。
- 文本资料收集、原件保留、标题/标签/事件日期、关键词检索、详情定位、隐私切换与可恢复清理队列。
- SQLite WAL、本机应用支持目录、单进程锁、请求与文件大小限制；普通日志不记录请求 URL 或资料正文。

### B2：本地解析与语义检索

- macOS PDFKit/Vision 本地 PDF 与图片 OCR，保留 PDF 页码；失败可见并可重试。
- llama.cpp 本地向量适配器，仅连接 `127.0.0.1`，禁用代理与重定向；向量归一化、模型标识变化后重建索引、关键词与语义结果融合。
- 固定 Qwen3-Embedding-0.6B Q8_0 来源、修订、大小与 SHA256；推荐 `1×4096` 上下文槽，避免运行时默认多槽高内存。

### B3：问答与外发控制

- 离线模拟明确标识且不发网络请求。
- DeepSeek 官方 API 适配器固定 HTTPS 地址，密钥仅从服务进程环境变量读取。
- 云端调用先在本机检索和选择片段，再展示实际问题、历史、片段、记忆、固定指令、完整 JSON、用途、预期结果、模型、地址与政策入口。
- 10 分钟进程内一次性确认凭据绑定 payload SHA256、用途、模型和地址；发送前重新读取资料、记忆与隐私。取消、过期、重启、内容变化或重复使用均不能发送。
- 不自动重试、不跟随重定向、不使用系统代理、不切换模型；60 秒超时与 4 MiB 响应上限。
- 外发记录保存用途、时间、模型、地址、来源标识、确认关联、摘要和状态，不重复保存请求正文或密钥。

### B4：个人记忆与备份

- 手动记忆、来源关联、确认/待确认/失效、修改历史、冲突提示、隐私与删除。
- 只有已确认、无冲突、允许外发且来源仍允许的记忆参与请求；来源删除或隐私收紧同步清理派生记忆、回答和外发记录。
- 停服状态下导出/恢复一致 SQLite 快照、原件与 SHA256 清单；恢复合并现有数据、保留更严格隐私、应用删除记录并重建向量。
- 旧缺陷版本问答历史和外发记录一次性清理；旧格式备份不恢复不完整历史。

### B5：运行与供应链记录

- Qwen 模型、llama.cpp、Homebrew 公式与 bottle、直接运行时依赖的来源、精确版本或修订、文件摘要、许可证与通知记录位于 `docs/THIRD_PARTY_NOTICES.md`。
- README 提供本机启动、OCR 构建、受限向量服务、DeepSeek 密钥本地配置与备份恢复方式。

## 最终候选的运行入口

在项目根目录构建系统提取器：

```sh
sh scripts/build-extractor.sh
```

启动已核准的本地向量服务：

```sh
llama-server -m '/Users/allenqiu/Library/Application Support/PersonalKnowledgeBase/models/Qwen3-Embedding-0.6B-Q8_0.gguf' --embedding --pooling last -ub 8192 -c 4096 -np 1 --host 127.0.0.1 --port 8766
```

在另一个终端启动知识库；不需要云端回答时可不配置 DeepSeek 密钥：

```sh
python3 -m pkb.server --embedding-port 8766 --embedding-model 06507c7b42688469c4e7298b0a1e16deff06caf291cf0a5b278c308249c3e439
```

如需 DeepSeek，在启动知识库的同一个终端先隐藏输入并导出 `DEEPSEEK_API_KEY`，具体命令见 README。配置密钥不代表同意发送；每次请求仍须在确认页单独确认。

## 已知限制

- 第一版面向 macOS 单用户、本机浏览器，不提供局域网访问、远程同步或公网托管。
- 音视频仅保留原件；云端图片理解未启用，图片优先使用本地 OCR。
- 向量检索采用精确扫描，适合第一版小规模个人资料；12 条合成样本不能代表所有真实资料。
- 备份为未加密 ZIP，上限 2 GiB，须保存在可信位置；旧备份无法知道其生成后的删除操作。
- 不承诺 DeepSeek API 零留存或一律不用于训练；模型别名、价格与政策可能变化，真实使用前以确认页和当时官方政策为准。
