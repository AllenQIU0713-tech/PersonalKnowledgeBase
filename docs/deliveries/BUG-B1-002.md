# BUG-B1-002 日期校验修复

根因：事件日期只在真值时调用日期解析，null/0 跳过校验并进入数据库，分别导致约束错误和无效日期持久化。

修复：在任何文件落盘前要求 event_time 为字符串；空字符串代表未填写，非空必须匹配 YYYY-MM-DD 并通过 date.fromisoformat 日历有效性解析。null、数字、布尔、数组、对象及非法日期统一返回明确 400。

版本：包含本文的修复提交，基于 8f8e191，包含 B1–B4 与前序整改。
状态：实现完成交复测，开发未运行测试。
复测：空串、合法日期、闰日、非法月日、null/0/false/数组/对象、导入失败时无原件或记录残留、日期过滤。
