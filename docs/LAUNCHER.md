# 1.0 一键启动设计与维护

用户要求：直接执行脚本启动项目，无需每次输入命令。按用户已授权的当前对话连续执行方式实施，不增加阶段审批或角色分发。

选择：根目录`启动知识库.command`配合Python标准库启动器。相比后台常驻服务，终端前台方式更容易看见状态并用Ctrl+C停止；相比手工两个终端，只需双击一次。暂不做打包App、开机自启或模型复用，避免额外安装与进程归属问题。

设计：仅启动现有Embedding模型（8766）和应用（8765），只监听127.0.0.1；启动前核对固定模型路径/大小、运行时及两个端口。任何端口占用均退出，不结束或复用未知服务。模型health就绪后启动应用，收到应用实际打印的一次性链接才自动打开默认浏览器；不保存凭证日志。Ctrl+C/TERM、异常或子进程退出都清理本次持有的子进程组。

默认资料目录是`~/Library/Application Support/PersonalKnowledgeBase`，执行启动脚本会打开并可能迁移正式库，不能把双击当成隔离测试。可传`--data-dir`指定合成目录。`--check`只检查文件/端口，不创建库、不启动模型或服务、不打开浏览器。源码包不含模型及本机OCR二进制。
